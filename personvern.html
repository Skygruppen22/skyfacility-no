Sky Facility Drift AS (org.nr. 930 893 307), Silurveien 2, 0380 Oslo, er behandlingsansvarlig for personopplysninger vi mottar via nettsiden.

Hva vi samler inn

Når du sender skjema, mottar vi navn, bedrift, e-post, telefon (hvis oppgitt), meldingstekst og eventuelle tjenester du har valgt. Vi bruker ikke markedsføringscookies på denne nettsiden.

Formål

Opplysningene brukes kun for å svare på henvendelsen og utarbeide tilbud om renholdstjenester.

Lagring

Vi lagrer henvendelser så lenge det er nødvendig for oppfølging og dokumentasjon av kundeforhold, typisk inntil saken er avsluttet eller avtalen opphører, med mindre lenger lagring kreves etter regnskapsloven.

Dine rettigheter

Du kan be om innsyn, retting eller sletting ved å kontakte hei@skyfacility.no. Du kan også klage til Datatilsynet.

Leverandører

Nettsiden hostes via GitHub Pages. Skjemadata kan formidles via FormSubmit for levering til vår e-post. Google Fonts kan laste skrifter fra Google.
